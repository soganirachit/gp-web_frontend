API Endpoints
All under /api/v1/bloombar/. Auth split: public = no JWT; admin = IsAdminUser.

Public (no auth required)
Method	URL	Purpose
GET	/bloombar/products/{product_id}/	Fetch product for QR scan
GET	/bloombar/hotels/{hotel_id}/	Hotel info for co-branding
POST	/bloombar/scan-events/	Record a QR scan (fire-and-forget)
POST	/bloombar/orders/	Create BloomBar order (pre-payment)
POST	/bloombar/payments/create-razorpay-order/	Get Razorpay order_id + key
POST	/bloombar/payments/verify/	Verify signature → mark order paid
GET	/bloombar/orders/{order_id}/	Poll order status post-payment
Admin (JWT, IsAdminUser)

GET/PUT/DELETE	/bloombar/qr-mappings/{id}/	QR mapping detail / edit
GET	/bloombar/admin/orders/	All BloomBar orders (filterable)

Payment Flow (reuses existing RazorpayService)

1. POST /bloombar/payments/create-razorpay-order/
   body: { order_id }   ← BloomBarOrder already created
   → calls RazorpayService.create_order(amount)
   → saves razorpay_order_id on BloomBarOrder
   → returns { razorpay_order_id, amount, currency, key_id }

2. Frontend opens Razorpay modal (client-side SDK)

3. POST /bloombar/payments/verify/
   body: { order_id, razorpay_order_id, razorpay_payment_id, razorpay_signature }
   → calls RazorpayService.verify_payment(...)
   → marks BloomBarOrder.status = 'paid'
   → triggers WhatsApp/email confirmation (existing notifications app)
   → updates linked QRScanEvent.converted = True, revenue = total_amount
